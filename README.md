# ESP32-8048S070C-CYD Display

ESP32-8048S070C - 7 inch TFT-LCD Display 800*480 pixels with LVGL 9.2.2

# Requirements
PlatformIO  

*Libraries:*  
LVGL 9.2.2  
TAMC_GT911 1.0.2  
GFX Library for Arduino 1.5.0

# How to use?
Just clone or download this repo and open the folder ESP32-8048S070C-CYD-Display with PlatformIO.

# Press Build 
it will download libraries and all necessary files and compile it

# Press Upload
connect you display with computer and click upload button,it will automatically detect port and will upload the code
